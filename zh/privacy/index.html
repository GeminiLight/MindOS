数据与控制

文件在本地，边界说清楚。

本地优先描述的是知识的存放位置。你选择的模型和服务，决定所选上下文还可能流向哪里。

01 / 在你的电脑上

MindOS 将知识保存在本地目录。你可以在 MindOS 或常用编辑器中查看、修改文件。导入或允许 Agent 大量修改前，请备份重要内容。

02 / 当 Agent 开始工作

已连接的客户端可以通过可用 MCP 工具和 Skills 访问相关知识。访问与执行行为取决于配置和客户端。请审阅重要改动与指令。

03 / 当你使用云模型

云模型可能接收完成任务所需的消息、文件片段与工具结果。这些数据适用对应服务商的政策。本地存储不等于所有 AI 处理都在设备内完成。

04 / 当你启用其他服务

配置的同步功能和第三方服务，可能向本地目录之外发送数据。启用前请检查设置与目标位置。

05 / 你可以先做的决定

选择一个小范围目录，检查 Agent 连接，先用非敏感示例笔记验证完整流程，再加入重要资料。
