开始使用

开始一次共同成长。

一个小知识库，加一个已连接的 Agent，就足够开始。

01 / 安装 MindOS

使用首页的桌面下载链接，或通过 CLI 安装。引导流程会帮助你选择知识目录并完成配置。

npm install -g @geminilight/mindos@latest
mindos onboard

02 / 连接兼容的 Agent

通过 Agent 设置流程配置 MCP 与随包提供的 MindOS Skill。先检查连接，再依赖共享的上下文工作。

mindos mcp install
mindos doctor agents

连接失败时，检查诊断输出和客户端的 MCP 配置。安装完成不代表所有客户端都已准备就绪。

03 / 完成第一次协作循环

创建一篇简短项目笔记，写清目标与约束。请 Agent 读取并建议下一步。审阅回复，纠正一个假设，再让它保存一条你确认过的经验。

04 / 检查，并持续掌控

打开变更文件，确认保存了什么。换一个会话或已连接的 Agent，明确请它读取这篇笔记。为重要文件保留备份。

本文基于当前 MindOS CLI；具体版本支持的选项请以 --help 为准。
