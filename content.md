### Is MindOS free?

MindOS is MIT open source. Models and third-party services may charge separately.

### Does co-evolution train the model?

It improves judgment and shared context. It does not change model weights.

### Can I use existing notes?

Yes. Test with a small Markdown folder and back up important files first.

### Will agents remember everything?

No. Set up the connection. Tools, instructions and the task determine what is read.

### Does all data stay local?

Files stay local. Cloud models or external services may receive selected context.

### Install MindOS

Use the desktop links on the homepage, or install the CLI. Onboarding guides you through the knowledge directory and configuration.

### Connect a supported agent

Configure MCP and the packaged MindOS Skill using the agent setup flow. Check the connection before relying on shared context.

### Complete your first loop

Create one short project note with the goal and constraints. Ask your agent to read it and suggest a next step. Review its response, correct one assumption, and ask it to save the lesson only after your review.

### Check and keep control

Open the changed file to confirm what was saved. Try another session or connected agent and explicitly ask it to read that note. Keep a backup of important files.

### On your computer

MindOS stores your knowledge in a local directory. You can inspect and edit the files using MindOS or your usual editor. Keep backups before importing or allowing substantial agent edits.

### When an agent works

A connected client can use available MCP tools and Skills to access relevant knowledge. Access and actions depend on configuration and the client’s behavior. Review important changes and instructions.

### When a cloud model is involved

A cloud model may receive the messages, file excerpts, and tool results needed for the task. Its provider’s policies apply to that data. Local file storage is not a promise that all AI processing stays on your device.

### When you enable other services

Configured synchronization and third-party services can send data outside the local directory. Check the settings and destination before enabling them.

### Your next decision

Choose a small starting directory, review the agent connection, and use non-sensitive example notes to check the complete workflow before adding important material.
