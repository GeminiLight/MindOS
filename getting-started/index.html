Getting started

Start a shared practice.

A small knowledge base and one connected agent are enough to begin.

01 / Install MindOS

Use the desktop links on the homepage, or install the CLI. Onboarding guides you through the knowledge directory and configuration.

npm install -g @geminilight/mindos@latest
mindos onboard

02 / Connect a supported agent

Configure MCP and the packaged MindOS Skill using the agent setup flow. Check the connection before relying on shared context.

mindos mcp install
mindos doctor agents

If a connection fails, read the diagnostic output and check your client’s MCP configuration. Do not assume installation alone makes every client ready.

03 / Complete your first loop

Create one short project note with the goal and constraints. Ask your agent to read it and suggest a next step. Review its response, correct one assumption, and ask it to save the lesson only after your review.

04 / Check and keep control

Open the changed file to confirm what was saved. Try another session or connected agent and explicitly ask it to read that note. Keep a backup of important files.
