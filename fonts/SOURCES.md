# Website fonts

Fonts are served locally; visitors do not request Google Fonts.

- `font-1.woff2`: existing IBM Plex Sans Latin asset; license `IBM-Plex-Sans-OFL.txt`.
- `font-2.woff2`: existing Lora italic Latin asset; license `Lora-OFL.txt`.
- `lora-regular-latin.woff2`: Lora normal 400 Latin, downloaded unchanged on 2026-10-15 from Google Fonts' first-party distribution. CSS: https://fonts.googleapis.com/css2?family=Lora:wght@400&display=swap ; file: https://fonts.gstatic.com/s/lora/v37/0QI6MX1D_JOuGQbT0gvTJPa787weuxJBkq18ndeYxZ0.woff2 . Same SIL Open Font License in `Lora-OFL.txt`.

The normal face prevents browsers from choosing the only previously available italic Lora face for every serif heading. Chinese glyphs retain the system serif fallback.
